隐私说明

字里 · Zili 是一个私人维护、非商业的学习工具。最后更新：2026 年 10 月

默认：一切都只在你的设备上

不登录的话，你的学习进度、自录单词、例句、录音和「我的文章」只保存在这台设备的浏览器里。我们看不到，也不会上传。没有广告，没有统计或追踪代码。

开启邮箱登录同步时

  • 存什么：你的邮箱地址，以及同步数据（学习进度、自录单词、例句、读过的文章标记；如果你勾选，还有「我的文章」）。不收集姓名、手机号或位置。
  • 存在哪里：Supabase 的欧盟服务器（爱尔兰都柏林）。
  • 谁能看到：只有你能通过 app 读写自己的数据。网站维护者在技术上可以访问数据库；如果你开启「加密我的数据」，数据在你的设备上加密后才上传，维护者和服务商都只能看到密文。
  • 邮件：只用来发送登录验证码，不发其他邮件。
  • 删除：在「设置 → 多设备同步」里点「删除账号和云端数据」，账号和云端数据会立刻永久删除。设备上的数据不受影响。

会连接的外部服务

  • 语音输入（字典里的麦克风按钮）：由浏览器自带的语音识别处理，iPhone 上交给苹果、Chrome 里交给谷歌。只有你按下麦克风时才会录音。手写识别和拍照识字都完全在设备上进行，照片不会上传。
  • Wiktionary（维基媒体）：查词先用本站自带的离线词典（CC-CEDICT、HanDeDict）；只有离线词典里没有的词，才会发给 Wiktionary。
  • Anthropic：只有你自己填了 API key 并使用 AI 功能时，相关文字或图片才会发给 Anthropic。key 只存在你的设备上。
  • Hugging Face：只有你在设置里下载开源神经语音时，才会从 Hugging Face 下载语音模型。朗读的文字在你的设备上处理，不会上传。
  • GitHub：app 本身和每日文章放在 GitHub Pages 上；选择 GitHub 同步方式时，数据加密后存进你自己的私有仓库。

字体和程序组件都放在本站，不会从谷歌等第三方加载。

联系

有问题或想删除数据，请联系介绍你使用这个工具的人，或在 GitHub 上留言。

Privacy (English)

Without login, everything stays in your browser on this device. No ads, no analytics, no tracking.

With email sync, we store your email address and your sync data (progress, your own words, sentences, read marks and optionally “My articles”) on Supabase servers in Dublin, Ireland (EU). Emails are only used for login codes. With “Encrypt my data” on, data is encrypted on your device before upload, so neither the maintainer nor the provider can read it. You can delete your account and cloud data at any time in Settings → Sync.

Speech input in the dictionary uses the browser’s own speech recognition (Apple on iPhone, Google in Chrome), only while the microphone button is on; handwriting and photo text recognition run on the device; photos are not uploaded. Word lookups use the built-in offline dictionary (CC-CEDICT, HanDeDict); only words it lacks are sent to Wiktionary; AI features (only with your own API key) go to Anthropic. If you download an open-source neural voice, its model is fetched from Hugging Face; the text being read is processed on your device and never uploaded. Fonts and libraries are self-hosted.

Datenschutz (Deutsch)

Ohne Anmeldung bleibt alles im Browser auf diesem Gerät. Keine Werbung, keine Analyse, kein Tracking.

Bei der E-Mail-Synchronisierung werden deine E-Mail-Adresse und deine Lerndaten (Fortschritt, eigene Wörter, Sätze, Lesemarken, optional „Meine Artikel“) auf Servern von Supabase in Dublin (Irland, EU) gespeichert. Die E-Mail dient nur dem Anmeldecode. Mit „Daten verschlüsseln“ werden die Daten schon auf dem Gerät verschlüsselt. Konto und Cloud-Daten kannst du jederzeit unter Einstellungen → Synchronisierung löschen.

Die Spracheingabe im Wörterbuch nutzt die Spracherkennung des Browsers (Apple auf dem iPhone, Google in Chrome), nur solange das Mikrofon an ist; Handschrift- und Fotoerkennung laufen auf dem Gerät; Fotos werden nicht hochgeladen. Wortabfragen nutzen das eingebaute Offline-Wörterbuch (CC-CEDICT, HanDeDict); nur Wörter, die dort fehlen, gehen an Wiktionary; KI-Funktionen (nur mit eigenem API-Schlüssel) an Anthropic. Wenn du eine Open-Source-Neuralstimme lädst, kommt das Modell von Hugging Face; der vorgelesene Text wird auf dem Gerät verarbeitet und nicht hochgeladen. Schriften und Bibliotheken liegen auf dieser Website.
