# Dictionary data in this folder

The files in `dict/` are built by `tools/build_dict.py` from:

- **CC-CEDICT** (Chinese–English), © MDBG and the CC-CEDICT contributors, https://cc-cedict.org/ — licence CC BY-SA 4.0
- **HanDeDict** (Chinese–German), © the HanDeDict contributors, published by Gábor L. Ugray, https://handedict.zydeo.net/ — licence CC BY-SA 3.0
- **jieba** word frequencies (`jieba/dict.txt`), https://github.com/fxsjy/jieba — MIT
- HSK levels from **complete-hsk-vocabulary**, https://github.com/drkameleon/complete-hsk-vocabulary — MIT

The definitions were shortened and merged (one entry per word and reading). This adapted dictionary data is shared under the same licence, **CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/). The app code is not part of this licence.
